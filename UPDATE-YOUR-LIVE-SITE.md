# Update the site you already created

1. Extract the Version 2 ZIP on your computer.
2. Open https://github.com/AlapawMan/bfar-4a-permit-guide
3. Click **Add file → Upload files**.
4. Drag in these four files from the extracted folder: **index.html**, **styles.css**, **script.js**, **data.js**. They replace the old versions. The download files have not changed.
5. Also upload **README.md**, **CONTENT-SOURCES.md**, **QA.md** and this update note to keep the documentation current.
6. Enter “Make the guide easier for students” as the commit message and click **Commit changes**.
7. Open **Actions**. Wait for the Pages deployment to show a green check.
8. Open https://alapawman.github.io/bfar-4a-permit-guide/ and refresh. On Windows, Ctrl+Shift+R refreshes without the old cached page.

Keep Pages set to **main → /(root)**. You do not need a new repository. The site will show “Easy-to-read guide · Version 2” near the top after the update.

This package is a local revision. It has not been uploaded to your GitHub repository by the assistant. Original sample files remain unavailable; the existing labeled draft aids are retained.
